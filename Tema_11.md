## Лабораторная работа №2
### Класс итератор с гибкой настройкой и удобными применением.

```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1

    def __iter__(self):
        return self

    def __next__(self):
        self.count -=1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__== "__main__":
    counter = CountDown(5)
    for i in counter:
        print(i)
```

### Результат.
![image](https://github.com/user-attachments/assets/ecd8531c-ec8b-4d02-8168-a991c29fb08f)

## Вывод
1. Определение класса `CountDown`: Создается класс, реализующий обратный отсчет.
2. Инициализация (`__init__`): Конструктор класса устанавливает начальное значение счетчика (self.count) на start + 1.
3. Метод `__iter__`: Возвращает сам объект класса, делая его итерируемым.
4. Метод `__next__`: Возвращает следующее значение счетчика, уменьшая его на 1 при каждом вызове. Вызывает исключение StopIteration, когда счетчик достигает -1, сигнализируя о конце итерации.
5. Использование в цикле `for`: Класс используется в цикле `for`, демонстрируя удобство и гибкость: автоматическая итерация до завершения.

## Лабораторная работа №5
### Такой же счетчик, как и в первом задании, только это генератор и использует yield.

```python
def countdown(count):
    while count>=0:
        yield count
        count -=1

if __name__== '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)
```

### Результат.
![image](https://github.com/user-attachments/assets/ace15914-4a94-4d4e-a98a-1b831311470f)

## Вывод
1. Определение функции-генератора `countdown`: Функция `countdown` использует `yield` для создания генератора, который производит обратный отсчет.
2. Цикл `while`: Цикл `while` итерируется, пока `count` больше или равно 0.
3. Ключевое слово `yield`: `yield count` возвращает текущее значение `count` и приостанавливает выполнение функции. При следующем вызове функция возобновляет работу с того места, где остановилась.
4. Уменьшение счетчика: `count -= 1` уменьшает значение счетчика на 1 после каждого вызова `yield`.
5. Создание генератора: `counter = countdown(5)` создает генератор, инициализируя его начальным значением 5.
6. Итерация с помощью цикла `for`: Цикл `for` перебирает значения, генерируемые генератором counter, и выводит их на консоль.

Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет воперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному).Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.

```python
def fib(n):
  a, b = 1, 1
  for _ in range(n):
    yield a
    a, b = b, a + b

fib_sequence = fib(200)

for i in range(199):
  next(fib_sequence)
print(f"200-е число Фибоначчи: {next(fib_sequence)}")
```

## Общие выводы по теме
Итераторы и генераторы в Python — мощные инструменты для эффективной обработки последовательностей данных. Итераторы предоставляют способ последовательного доступа к элементам, не загружая всю последовательность в память сразу. Генераторы, являющиеся особым типом итераторов, создаются с помощью функции и ключевого слова `yield`, позволяя генерировать элементы по запросу. Это особенно полезно для работы с большими наборами данных или бесконечными последовательностями, где хранение всей информации в памяти невозможно или нецелесообразно. Итераторы и генераторы повышают производительность и эффективность кода, делая его более читаемым и поддерживаемым.
